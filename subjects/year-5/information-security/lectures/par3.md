## ١. مقدمة عن التشفير غير المتناظر

::: {.box .box-def}
**🔑 التعريف** في [Asymmetric Cryptography (Public Key
Encryption)]{.ltr} يمتلك كل طرف **زوجاً من المفاتيح**:

-   **المفتاح العام (Public Key):** معروف للجميع.
-   **المفتاح الخاص (Private Key):** خاص بمالكه فقط، ولا يجب لأي شخص آخر
    معرفته.

القاعدة العامة: يتم التشفير بأحد المفتاحين وفك التشفير بالمفتاح الآخر.
الحالة الشائعة: **تشفير بالمفتاح العام → فك تشفير بالمفتاح الخاص**.
:::

## ٣. [Modular Arithmetic]{.ltr}

::: {.box .box-def}
**🔑 التعريف** [a ≡ b (mod m)]{.ltr} إذا وفقط إذا كان الناتج [(a − b) /
m = k]{.ltr} عدداً صحيحاً [(k ∈ Z)]{.ltr}.\
تُسمى [m]{.ltr} بـ **[modulus]{.ltr} (المقياس)**.
:::

::: {.box .box-example}
**📘 أمثلة (من المحاضرة)**

  العلاقة            الحساب                     النتيجة
  ------------------ -------------------------- --------------
  15 ≡ 9 (mod 2)     (15−9)/2 = 3 ∈ Z           ✅ صحيحة
  15 ≡ 7 (mod 5)     (15−7)/5 = 8/5 = 1.6 ∉ Z   ❌ غير صحيحة
  70 ≡ 50 (mod 10)   (70−50)/10 = 2 ∈ Z         ✅ صحيحة
  27 ≡ 2 (mod 5)     (27−2)/5 = 5 ∈ Z           ✅ صحيحة
:::

::: {.box .box-tip}
**💡 نصيحة سريعة للحفظ** للتحقق من [a ≡ b (mod m)]{.ltr}: اطرح [b]{.ltr}
من [a]{.ltr} واقسم الناتج على [m]{.ltr}. إذا خرجت القسمة عدداً صحيحاً بدون
كسور، فالعلاقة صحيحة --- وإلا فهي خاطئة.
:::
:::

::: {#euler .section .content-section}
## ٤. دالة أويلر [Euler Phi (Totient) function φ(n)]{.ltr}

::: {.box .box-def}
**🔑 التعريف** [φ(n)]{.ltr} هو عدد الأعداد الصحيحة ضمن المجال [\[1,
n\]]{.ltr} التي تكون **أولية مع [n]{.ltr}** (أي القاسم المشترك الأكبر
بينها وبين [n]{.ltr} يساوي 1).
:::

  n   φ(n)   التفصيل
  --- ------ --------------------------
  2   1      φ(2) = \|{1}\| = 1
  3   2      φ(3) = \|{1,2}\| = 2
  4   2      φ(4) = \|{1,3}\| = 2
  5   4      φ(5) = \|{1,2,3,4}\| = 4
  6   2      φ(6) = \|{1,5}\| = 2

::: {.box .box-warning}
**⚠️ مهم للامتحان --- تُستخدم مباشرة في [RSA]{.ltr}**

1.  إذا كان [n]{.ltr} عدداً أولياً: [φ(n) = n − 1]{.ltr}
2.  إذا كان [p, q]{.ltr} عددين أوليين: [φ(p×q) = φ(p)×φ(q) =
    (p−1)×(q−1)]{.ltr}
:::
:::

::: {#owf .section .content-section}
## ٥. [One Way Function]{.ltr}

::: {.box .box-def}
**🔑 التعريف** الدالة [y = f(x)]{.ltr} تكون **أحادية الاتجاه** إذا تحقق:

1.  من خلال معرفة [x]{.ltr} يمكن حساب [y]{.ltr} بسهولة.
2.  من خلال معرفة [y]{.ltr} لا يمكن (من غير المجدي عملياً) حساب [x]{.ltr}
    --- أي أن حساب [f⁻¹]{.ltr} مكلف حسابياً جداً.
:::

::: {.box .box-example}
**📘 مثال** [n = p × q]{.ltr} تكون دالة أحادية الاتجاه إذا كان يمكن
معرفة [n]{.ltr} من خلال معرفة [p, q]{.ltr} بسهولة، لكن لا يمكن معرفة [p,
q]{.ltr} من خلال معرفة [n]{.ltr} فقط. (هذا هو أساس أمان [RSA]{.ltr}.)
:::
:::

::: {#rsa .section .content-section}
## ٦. خوارزمية [RSA]{.ltr} [(Rivest, Shamir, Adleman, 1977)]{.ltr}

### أ) توليد المفاتيح [(Key Generation)]{.ltr}

1.  اختيار عددين أوليين كبيرين جداً [p, q]{.ltr}.
2.  حساب [n = p × q]{.ltr} وحساب [φ(n) = φ(p)×φ(q) = (p−1)(q−1)]{.ltr}.
3.  حساب المفتاح العام [e]{.ltr}: عدد عشوائي أصغر من [φ(n)]{.ltr} وأولي
    معه، أي [e \< φ(n)]{.ltr} و [gcd(e, φ(n)) = 1]{.ltr}.
4.  حساب المفتاح الخاص [d]{.ltr}: يجب أن يحقق [e × d ≡ 1 (mod
    φ(n))]{.ltr}، حيث [0 ≤ d ≤ n]{.ltr}.
5.  المفتاح العام النهائي: [{e, n}]{.ltr} --- المفتاح الخاص النهائي:
    [{d, p, q}]{.ltr}.

### ب) التشفير وفك التشفير

::: {.box .box-def}
تشفير الرسالة [M]{.ltr} بالمفتاح العام: [C = Mᵉ mod n]{.ltr}، حيث [0 ≤ M
\< n]{.ltr}.\
فك التشفير بالمفتاح الخاص: [M = Cᵈ mod n]{.ltr}.
:::

### ج) مثال تطبيقي كامل (بنفس أرقام المحاضرة)

::: {.box .box-example}
**📘 مثال بسيط**

1.  [p = 3]{.ltr}، [q = 11]{.ltr}
2.  [n = p×q = 33]{.ltr}
3.  [φ(n) = (p−1)×(q−1) = 2×10 = 20]{.ltr}
4.  نختار [e = 7]{.ltr}
5.  نبحث عن [d]{.ltr} بحيث [(d×7) mod 20 = 1]{.ltr} → [d = 3]{.ltr}
6.  لتشفير الرسالة [M = 2]{.ltr} بالمفتاح العام: [C = 2⁷ mod 33 =
    29]{.ltr}
7.  فك التشفير بالمفتاح الخاص: [M = 29³ mod 33 = 2]{.ltr} ✅ (عادت
    الرسالة الأصلية)
:::

::: diagram
::: {.node .key}
p=3, q=11
:::

::: arrow
→
:::

::: node

:::

::: arrow

::: {.node .key}

:::

:::

::: {.box .box-warning}
**⚠️ مهم للامتحان** الشرط [e × d mod φ(n) = 1]{.ltr} هو قلب خوارزمية
[RSA]{.ltr} --- احفظه جيداً، فمعظم أسئلة الحساب تدور حوله.
:::

::: {#signature .section .content-section}
## ٧. التوقيع الالكتروني / الرقمي [(Digital Signature)]{.ltr}

::: {.box .box-def}
**🔑 المفاهيم** **[Message Authentication]{.ltr}:** التأكد من مصدر
الرسالة (هوية المرسل) ومن سلامتها [(integrity)]{.ltr}.\
**[Digital Signature]{.ltr}:** تقنية تحقق [Message Authentication]{.ltr}
وتضمن أيضاً خدمة **منع الإنكار [(non-repudiation)]{.ltr}**.
:::

::: {.box .box-example}
**⚙️ كيف يتحقق التوقيع الرقمي؟** من خلال دمج [Hash Function]{.ltr} مع
التشفير غير المتناظر:

1.  يُحسب ناتج [hash function]{.ltr} للرسالة.
2.  يُشفَّر ناتج الـ [hash]{.ltr} بالمفتاح **الخاص** للمرسل (هذا هو
    \"التوقيع\").
3.  يقوم المستقبل بفك التشفير باستخدام المفتاح **العام** للمرسل للتحقق.
:::

::: {.box .box-warning}
**⚠️ مهم للامتحان --- عكس التشفير العادي!**

                   خطوة الإرسال                                خطوة الاستقبال
  ---------------- ------------------------------------------- ------------------------------
  التشفير العادي   تشفير بالمفتاح **العام**                    فك بالمفتاح **الخاص**
  التوقيع الرقمي   توقيع (تشفير الـ hash) بالمفتاح **الخاص**   تحقق (فك) بالمفتاح **العام**
:::
:::

::: {#hash .section .content-section}
## ٨. [Hash Function]{.ltr}

::: {.box .box-def}
**🔑 التعريف** تابع يأخذ الرسالة [M]{.ltr} (ذات حجم متغير) ويُعطي قيمة
مميزة بطول ثابت تسمى: [imprint]{.ltr} / [digital fingerprint]{.ltr} /
[message digest]{.ltr}.
:::

::: diagram
::: node
رسالة بطول متغير [M]{.ltr}
:::

::: arrow
→
:::

::: {.node .key}
[Hash Function]{.ltr}
:::

::: arrow
→
:::

::: node
بصمة بطول ثابت [(digest)]{.ltr}
:::
:::

-   أي تغيير في الرسالة [M]{.ltr} --- ولو بسيط --- يؤدي إلى تغيير قيمة
    الـ [hash]{.ltr} الناتجة بالكامل.
-   توابع الهاش هي [one way function]{.ltr} (لا يمكن استرجاع [M]{.ltr}
    من الـ [digest]{.ltr}).

  الخوارزمية                       طول الخرج
  -------------------------------- -----------
  MD5 (Message-Digest Algorithm)   128 bit
  SHA-1 (Secure Hash Algorithm)    160 bit
  SHA-256                          256 bit
  SHA-512                          512 bit

::: {.box .box-tip}
**💡 نصيحة سريعة للحفظ** في عائلة [SHA-XXX]{.ltr} الرقم في الاسم = طول
الخرج بالبت مباشرة ([SHA-256 → 256 bit]{.ltr}, [SHA-512 → 512
bit]{.ltr}) باستثناء [SHA-1]{.ltr} الذي طوله [160 bit]{.ltr} --- استثناء
يجب حفظه غيباً.
:::
:::

::: {#revision .section .content-section}
## 📌 المراجعة السريعة [(Quick Revision)]{.ltr}

::: revision-grid
<div>

### المفاهيم والتعاريف

-   تشفير غير متناظر = زوج مفاتيح (عام + خاص) لكل طرف.
-   التشفير العادي: عام يشفّر ← خاص يفك.
-   التوقيع الرقمي: خاص يوقّع ← عام يتحقق (عكس التشفير!).
-   [a ≡ b (mod m)]{.ltr} ⇔ [(a−b)/m ∈ Z]{.ltr}.
-   [φ(n)]{.ltr}: عدد الأعداد الأولية مع [n]{.ltr} ضمن [\[1,n\]]{.ltr}.
-   [One Way Function]{.ltr}: سهل الحساب مباشرة، مستحيل عملياً بالعكس.
-   [Hash Function]{.ltr}: خرج بطول ثابت (بصمة) من رسالة بطول متغير، وهي
    [one-way]{.ltr}.

</div>

<div>

### الصيغ الأساسية

-   φ(n) = n − 1 (n prime)
-   φ(p×q) = (p−1)(q−1)
-   e × d ≡ 1 (mod φ(n))
-   C = Mᵉ mod n (encryption)
-   M = Cᵈ mod n (decryption)
-   مفتاح عام [RSA]{.ltr} = [{e, n}]{.ltr} --- مفتاح خاص = [{d, p,
    q}]{.ltr}
-   MD5=128bit \| SHA-1=160bit \| SHA-256=256bit \| SHA-512=512bit

</div>

## 📝 أسئلة تدريبية تفاعلية

اضغط على الإجابة لمعرفة إن كانت صحيحة، ثم اقرأ التوضيح.

::: mcq-card
١. في التشفير غير المتناظر، أي المفاتيح يُسمح لأي شخص معرفته؟

::: mcq-options
المفتاح الخاص

المفتاح العام

كلا المفتاحين

لا أحد منهما
:::

::: mcq-explanation
المفتاح العام معروف للجميع، أما المفتاح الخاص فيبقى سرياً لدى صاحبه فقط.
:::
:::

::: mcq-card
٢. هل العلاقة [15 ≡ 7 (mod 5)]{.ltr} صحيحة؟

::: mcq-options
صحيحة، لأن الفرق يساوي 8

غير صحيحة، لأن 8/5 ليس عدداً صحيحاً

صحيحة دائماً عند طرح أي عددين

لا يمكن تحديد ذلك
:::

::: mcq-explanation
[(15−7)/5 = 8/5 = 1.6]{.ltr} وهو ليس عدداً صحيحاً، لذلك العلاقة غير صحيحة.
:::
:::

::: mcq-card
٣. ما قيمة [φ(7)]{.ltr} علماً أن 7 عدد أولي؟

::: mcq-options
7

5

6

1
:::

::: mcq-explanation
إذا كان [n]{.ltr} عدداً أولياً فإن [φ(n) = n − 1 = 7 − 1 = 6]{.ltr}.
:::
:::

::: mcq-card
٤. دالة [One Way Function]{.ltr} تعني أن:

::: mcq-options
يمكن حساب x وy بنفس السهولة في الاتجاهين

لا يمكن حساب y من x إطلاقاً

حساب y من x سهل، وحساب x من y غير مجدٍ عملياً

تُستخدم فقط في التوقيع الرقمي
:::

::: mcq-explanation
من x يمكن حساب y بسهولة، لكن العكس (حساب f⁻¹) مكلف حسابياً جداً وغير مجدٍ
عملياً.
:::
:::

::: mcq-card
٥. في مثال [RSA]{.ltr} حيث [p=3, q=11]{.ltr}، ما قيمة [n]{.ltr}
و[φ(n)]{.ltr}؟

::: mcq-options
n=14, φ(n)=8

n=33, φ(n)=20

n=33, φ(n)=33

n=30, φ(n)=20
:::

::: mcq-explanation
[n = p×q = 3×11 = 33]{.ltr}، و[φ(n) = (p−1)(q−1) = 2×10 = 20]{.ltr}.
:::
:::

::: mcq-card
٦. يتكون المفتاح العام في [RSA]{.ltr} من:

::: mcq-options
[{d, n}]{.ltr}

[{d, p, q}]{.ltr}

[{e, n}]{.ltr}

[{e, p, q}]{.ltr}
:::

::: mcq-explanation
المفتاح العام = [{e, n}]{.ltr}، بينما المفتاح الخاص = [{d, p, q}]{.ltr}.
:::
:::

::: mcq-card
٧. في التوقيع الرقمي، يقوم المرسل بتشفير ناتج الـ [hash]{.ltr} باستخدام:

::: mcq-options
المفتاح العام الخاص به

المفتاح الخاص به

المفتاح العام للمستقبل

مفتاح متناظر مشترك
:::

::: mcq-explanation
عكس التشفير العادي: المرسل يوقّع (يشفّر الـ hash) بمفتاحه الخاص، والمستقبل
يتحقق بالمفتاح العام للمرسل.
:::
:::

::: mcq-card
٨. أي خدمة أمنية يضمنها التوقيع الرقمي إضافة إلى التحقق من الهوية؟

::: mcq-options
السرية [(Confidentiality)]{.ltr}

منع الإنكار [(Non-repudiation)]{.ltr}

التوفر [(Availability)]{.ltr}

التحكم بالوصول [(Access Control)]{.ltr}
:::

::: mcq-explanation
التوقيع الرقمي يضمن [Message Authentication]{.ltr} بالإضافة إلى
[non-repudiation]{.ltr} (منع تنصل المرسل من الرسالة).
:::
:::

::: mcq-card
٩. طول خرج خوارزمية [MD5]{.ltr} هو:

::: mcq-options
[160 bit]{.ltr}

[128 bit]{.ltr}

[256 bit]{.ltr}

[512 bit]{.ltr}
:::

::: mcq-explanation
[MD5]{.ltr} ينتج بصمة بطول [128 bit]{.ltr} ثابت بغض النظر عن طول الرسالة
الأصلية.
:::
:::

::: mcq-card
١٠. لماذا تُعتبر توابع الهاش [One Way Function]{.ltr}؟

::: mcq-options
لأنها تُستخدم مرة واحدة فقط لكل رسالة

لأن طول الخرج يساوي طول الرسالة دائماً

لأنه لا يمكن استرجاع الرسالة الأصلية من قيمة الـ hash

لأنها تُستخدم فقط في تشفير الملفات
:::

::: mcq-explanation
يمكن حساب الـ [hash]{.ltr} من الرسالة بسهولة، لكن يستحيل عملياً استرجاع
الرسالة الأصلية من قيمة الـ [hash]{.ltr} --- وهذا جوهر [one-way
function]{.ltr}.
:::
